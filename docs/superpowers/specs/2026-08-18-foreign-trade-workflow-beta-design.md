# 外贸客户工作流 Beta 设计

## 目标

在不破坏现有证据链、稳定编号、机器字段和风险门的前提下，为业务员提供一个可以从路线选择一路操作到客户沟通的单一入口。Beta 先支持一名业务员编辑，后续多人协作另行设计。

## 设计结论

采用“一个业务前台 + 三个专业后台 + 一个可替换采集执行器”的结构：

- `foreign-trade-workflow-director` 是唯一面向业务员的流程入口和业务工作簿所有者。
- `industry-application-map-builder` 维护共享行业/应用证据、公司地图和路线池，不搜索客户。
- `foreign-trade-customer-development` 编译方向、生成采集任务、接收原始批次、独立复核候选、执行背调并交接沟通。
- `foreign-trade-customer-operations` 准备首封、跟进、回复和客户经营建议，不研究新客户、不发送。
- Cowork 或其他执行器只执行明确的采集任务，追加原始批次；它不是裁判，也不写业务工作簿。
- 业务员决定路线、客户分类、跟进、风险处置、最终内容和发送。

## 为什么新增业务工作簿

现有行业骨架、应用知识、公司地图和客户开发工作簿是机器合同与证据库。直接把其中的机器页改名或删减，会破坏字段合同、脚本和审计链；继续把它们展示给业务员，又会造成操作负担。

因此新增独立的 `salesperson-foreign-trade-workbench.xlsx`，只呈现业务动作和决策。后台工作簿保持原结构，通过稳定编号和来源引用关联。

## 六个业务页

| 工作表 | 业务问题 | 主要动作 |
|---|---|---|
| `00-我的待办` | 我现在要做什么 | 按状态查看待办，记录处理结果 |
| `01-路线选择` | 哪条路线值得进入开发 | 选择编译、继续核实、暂缓或淘汰 |
| `02-候选客户` | 哪些公司进入下一步 | 选择初查、潜力客户、暂缓或淘汰 |
| `03-客户跟进` | 客户下一步做什么 | 记录下一动作、日期和客户状态 |
| `04-沟通草稿` | 哪些草稿需要审核 | 审核、退回修改或批准内容；不代表发送 |
| `05-异常与风险` | 哪些问题阻止继续 | 处理证据过期、接口失败、风险暂停和待核实项 |

每页只保留完成当前业务动作必需的字段；机器详情通过 `source_record_id`、`source_packet_reference` 和 `evidence_reference` 回溯。

## 候选采集拆分

旧 `candidate_scan` 作为兼容入口保留，但必须在内部明确路由到三个互斥阶段：

1. `candidate_task_export`：将已确认方向和声明范围写成只读采集任务；不产生候选结论。
2. `candidate_batch_intake`：接收采集执行器的追加式原始批次；只做格式、范围、重复项和来源存在性检查，不判断合格。
3. `candidate_review`：由客户开发技能基于直接证据门独立复核，分开输出合格、排除和未核实项，随后停止等待业务员筛选。

任务发出者、采集执行者和结果复核者不得在一个不可审计步骤中合并。

## 写入边界

- 流程协调技能只有在用户明确授权时才能写业务工作簿；写入后必须重开核对。
- 专业技能继续拥有其后台工作簿和交接包；不直接覆盖业务员字段。
- 采集执行器只能追加原始批次，不能改旧批次、方向状态、候选结论或业务员决定。
- 工作簿状态只允许 `未写入`、`待授权` 或 `已重开验证`。
- 任何共享输入哈希变化，必须在 `05-异常与风险` 显示过期并阻止后续扫描，直到重新验证与导出。

## 审核与决策

- 复核只输出 `PASS / FAIL / UNVERIFIED` 和逐项理由，不生成综合分。
- 正例数量、候选数量或“没有搜到”不能自动决定方向保留或淘汰。
- 草稿、业务员批准、实际发送和实际回复必须分开。
- 风险暂停、回复或疑似回复的硬门高于日期到期和普通跟进。

## Beta 验收

1. 新插件、技能入口、六页空白工作簿和契约测试均存在。
2. 工作簿结构、下拉状态、公式、冻结窗格、筛选、中文说明和可读性通过重开检查。
3. 三个专业技能明确接受协调器交接，同时保留各自边界。
4. 候选采集的任务、原始批次和复核阶段可独立追溯。
5. 旧机器工作簿字段和脚本测试不因业务前台而失效。
6. 本轮只交付未提交、未安装的本地 Beta 源码；真实客户效果留待安装后的受控实测。

## 回滚

本轮不修改真实业务数据。若 Beta 不适用，可丢弃未提交改动；即使以后提交，删除新增协调插件并恢复三个专业技能的本次接口增量，也不会删除原机器工作簿或历史证据。
