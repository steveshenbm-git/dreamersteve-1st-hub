本目录只保存 `[COMPANY_ID]` 的来源、事实、产品体系、交接包和工作材料。先封存来源，再登记原子事实；不得复制其他公司的业务事实作为示例。

## 使用顺序

1. 将原件复制到 `01-源文件封存/`，不改写原件内容。
2. 计算 SHA-256，并登记到 `00-管理/源文件清单.json`；不得给整份来源设置一个证据等级。
3. 将来源中的陈述拆成 `02-事实库/facts.json` 原子事实；新来源事实默认 E1。
4. 仅在明确审核后升级具体事实至 E2 或 E3，并记录审核人、日期和允许用途。
5. 在 `03-产品体系/product-system.json` 建立产品族、系列和型号关系，不补造缺失层级。
6. 只将审核通过的 E3 自有公司事实 ID 放入开发交接包的 `confirmed_*` 字段。
7. 每次写入后运行 `validate_company_library.py`。

目录隔离属于工作流隔离，不等同于操作系统权限、加密或物理隔离。
