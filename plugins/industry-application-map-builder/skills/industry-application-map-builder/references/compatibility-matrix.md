# RC2 内容优先统一版本兼容矩阵

| Producer or artifact | Consumer | Result | Rule |
| --- | --- | --- | --- |
| beta.3 strict contract without `execution_mode` | Same-name upgraded map/controller | PASS as `strict_audit` compatibility | Run the retained beta.3 validator/evaluator unchanged. |
| beta.3 strict `EFFECTIVE` report | Content-first lane | UNVERIFIED | Do not relabel it as content-first evidence. |
| Content-first contract/report | beta.3 installed skills | UNVERIFIED | beta.3 cannot read it as strict admissibility or `EFFECTIVE`. |
| Content-first 40-case PASS | Same-name content-first full-scope gate | Waiting only | Requires explicit full-scope authorization and unchanged terminal scope. |
| Content-first full-scope research | Company map, route, customer, shared base | BLOCKED | `RESEARCH_ONLY_BLOCKED` remains mandatory. |
| Complete R4 content evidence with missing platform audit alone | Same-name beta.3 R4 scorer | Continue content scoring; platform audit stays UNVERIFIED | Platform identity/transport cannot replace or veto an otherwise complete content scorecard by itself. |
| `0.4.0-beta.4` R4 contract with `case_package_contract_version = 1.0-beta4`, complete raw-capture truth and both R4 arms | Same-name beta.4 R4 validator/evaluator | PASS only after deterministic validation | Use `baseline_full_depth_v1`, `screen_then_expand_v2`, real 80-task evidence and six frozen repeats. |
| `0.4.0-beta.3` R4 contract | Beta.4 | historical read-only only | Do not continue, relock or finalize it; prepare a new beta.4 contract root. |
| R4 artifact with its marker or R4 arm fields removed | Legacy reader | FAIL: `legacy downgrade` refused | Missing fields never select compatibility; restore the immutable R4 artifact or regenerate it from frozen inputs. |
| Explicit frozen `1.0-legacy` scorecard contract with no R4 arm declarations | Retained legacy content validator | Legacy-compatible only | The exact legacy marker, allowlisted frozen version and matching five-item schema are all required. |

Rollback means retaining append-only content-first artifacts and returning to the versioned beta.3 Git commit or tag. Never overwrite a content-first run, alter beta.3 hashes, or merge content-first records into RC2-40-R2.
