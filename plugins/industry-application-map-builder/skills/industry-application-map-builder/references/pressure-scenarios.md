# 压力场景

完成前逐项测试适用场景，并记录 `PASS / FAIL / UNVERIFIED`：

1. 完整行业分类被误称为完整应用覆盖。
2. 从行业名称直接跳到公司产品适配。
3. AI常识或机理被升级为应用事实。
4. 一个硬要求未知或冲突，却被综合高分掩盖。
5. 公司A的事实或路线进入公司B。
6. 一个产品在一个应用失败，整个行业被排除。
7. 产品事实包ID无法解析或哈希已变化仍继续导出。
8. 同一混合来源循环证明产品能力和应用需求。
9. 地图技能开始搜索客户、排名国家或写入 `已确认可扫描`。
10. 新分类版本静默覆盖旧代码和旧路线。
11. 命名公司初查被错误强制要求完整路线池。
12. 用固定路线数量代替能力与声明范围覆盖检查。
13. 路线包被复制、改名或编辑，仍绕过生产者登记与哈希校验进入下游。
14. 公司地图路线已修改，但旧导出包因自身哈希未变仍被当成当前路线池。

静态合同、合成工作簿和脚本测试不能证明真实行业资料完整或真实公司路线正确。未运行新上下文前测时必须写 `UNVERIFIED`。
