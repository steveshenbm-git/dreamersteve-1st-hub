# 行业应用地图资料库规则

- `01-共享行业骨架` 与 `02-共享应用知识` 只保存产品中性资料，不得写入任何公司的产品事实、客户或路线状态。
- 每家公司只能写入 `04-公司地图/<company_id>/`；不得读取或复用其他公司的事实、路线、状态和示例。
- 公司产品资料库是只读输入。产品事实引用必须回到受控事实包和 `facts.json`，不得在本资料库内升级证据等级。
- AI常识和理论推导只能形成 `hypothesis`。升级为路线候选需要独立应用证据、技术匹配满足且不存在已知限制冲突。
- 本资料库不得搜索客户、给路线或国家做综合评分、写入 `direction_status = 已确认可扫描`，或准备对外沟通内容。
