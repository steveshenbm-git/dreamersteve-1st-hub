# Production Success Strategy Gate

Use this before high-impact, cost-bearing, brief-based, or repeated-failure image production. This gate improves the chance of a useful first draft; it is not a delivery review.

## Core Rule

Do not rely on repeated generation to discover a good image. Before production, state why the selected method, visual model, and controlled variables can satisfy the current intent and brief.

The method must have a credible ceiling for purpose fit, truthfulness/realism, and visual quality together. Do not select a method that reaches one factor by knowingly weakening another.

## How To Improve Hit Rate

- Start from a visual model: subject, spatial relationship, visual hammer, hierarchy, negative space, and visible carriers.
- Define the relationship before style: foundation, driver, outcome, and feedback when multiple ideas must collaborate.
- Control only a few variables per attempt. Do not change subject, color, crop, medium, light, material, and message all at once.
- Use the method that can reach the requested visual grade, not the method that is easiest to save locally.
- Test the method ceiling against all three inherited factors. A photographic method is not automatically truthful; a deterministic method is not automatically precise enough; a polished method is not automatically fit for purpose.
- For important text, logo, CTA, crops, exports, and review files, use deterministic post-processing when possible.
- For realistic scene, natural texture, product, equipment, or atmospheric visuals, avoid final script/SVG geometry unless the user explicitly requested flat/vector style.

## Hard Stops

Stop before production when:

- the brief needs a long explanation to seem workable;
- named concepts have no visible carrier or page-copy carrier;
- the method cannot plausibly reach the required visual grade;
- the method cannot preserve the accepted purpose, evidence boundary, or truthfulness/realism mode while reaching that visual grade;
- the visual model is only color, glow, gradient, or atmosphere;
- a prior failed method is being repeated with only prompt wording changed;
- the next attempt has no distinct hypothesis.
- the strategy relies on one factor compensating for a known failure in another.

If stopped, return to Workflow Director or planner with the missing decision, method limitation, or brief weakness. Do not generate first and hope review will fix it.
